# Introduction
This is Create Stackpress App, an open-source CLI tool that helps scaffold **[Stackpress](https://stackpress.io)** applications.

# Setup
Install the generator as a global package:
```sh
npm i -g create-stackpress-app
```

Run the package where you want to create a stackpress project:
```sh
create-sp-app
```
